# Sea Level Predictor

This project is part of the freeCodeCamp Data Analysis with Python Certification.

## Features

- Sea level scatter plot
- Linear regression prediction
- Future sea level prediction till 2050
- Trend analysis using historical and recent data

- Python
- Pandas
- Matplotlib
- SciPy
- NumPy

- main.py

